## Portfolio Implications

- Lead with the tested PAM simulator and security gateway, and label design-only directory work accurately.
- Keep access reviews, MFA, directory groups, and privilege controls visible as documented knowledge.
- Do not imply experience with SailPoint, ServiceNow, production provisioning, or live Entra ID/AD administration; this repo does not currently evidence those tools or environments.
- The clearest future proof gap is a small, completed joiner-mover-leaver workflow with test identities, approvals, verification, and audit evidence.
